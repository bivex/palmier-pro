# Архитектура и разграничения Palmier Pro (29.07.2026)

Документ описывает разделение архитектурных компонентов Palmier Pro на открытую (Open Source) клиентскую часть и закрытый (Closed Source) облачный бэкенд обработок Generative AI.

## 2. Клиентская часть (Open Source)

Вся локальная функциональность видеоредактора открыта под лицензией **GPLv3** и выполняется на устройстве пользователя (macOS 26, Apple Silicon).

* **Ядро видеоредактора**: Написано на Swift 6.2 (SwiftUI, AppKit, AVFoundation). Выполняет монтаж, работу с таймлайном, эффекты, аудиомикширование и экспорт.
* **Встроенный MCP-сервер (`http://127.0.0.1:19789/mcp`)**: Предоставляет стандартный интерфейс Model Context Protocol для управления таймлайном из внешних AI-инструментов (Claude Code, Cursor, Codex и др.).
* **Локальный агент (In-app Agent)**: Чат-интерфейс внутри приложения, который использует те же встроенные доменные операции и инструменты редактора, что и внешний MCP-сервер.
* **Изоляция и автономность**: Редактор может функционировать полностью офлайн как классический видеоредактор (аналог CapCut / Premiere Pro) без необходимости авторизации.

## 3. Облачная часть и Generative AI (Closed Source)

Генерация видео, изображений и аудио с использованием SOTA-нейросетей является закрытым облачным сервисом Palmier, требующим авторизации и подписки.

### Точки интеграции в коде:
* **Модуль `GenerationBackend.swift`** (`Sources/PalmierPro/Generation/GenerationBackend.swift`):
  * **Авторизация и сессия**: Управляется через `AccountService.shared.convex`.
  * **Загрузка референсов**: Функция `uploadReference` отправляет временные файлы через мутацию `"uploads:commitUpload"`.
  * **Создание задачи генерации**: Функция `submit` отправляет параметры и идентификатор модели через мутацию `"generations:submit"`.
  * **Отслеживание статуса**: Подписка в реальном времени через Convex (`convex.subscribe` на `"generations:byId"`) получает обновления статусов (`queued`, `running`, `succeeded`, `failed`) и итоговые URL-адреса готовых медиафайлов.

### Бэкенд-сервисы Palmier:
1. **Управление подписками и биллингом**: Учет кредитов пользователя.
2. **Маршрутизатор API**: Безопасное взаимодействие с провайдерами генеративных моделей (ByteDance Seedance, Kuaishou Kling, Nano Banana Pro, Grok, Veo и др.).
3. **Хранилище результатов**: Временное хранение и раздача сгенерированного медиа-контента.
